# 校园快递代取跑腿管理系统

## 项目简介
校园快递代取跑腿管理系统旨在解决学生快递积压、取件不便的问题。平台连接发布任务的学生与接单的跑腿员，实现代取、配送、送达的全流程管理。核心功能包括：用户注册与角色切换、订单发布与浏览、在线接单、状态跟踪。

## 技术栈
- **后端**：Java 17 + Spring Boot  + MyBatis-Plus
- **前端**：Vue3 + Vite + Element Plus + Axios + Pinia
- **数据库**：MySQL 8.0
- **版本控制**：Git + GitHub
