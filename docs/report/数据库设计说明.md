# 校园跑腿系统数据库设计文档
## 一、数据库基础信息
- 数据库名称：`springbootrv41o`
- 编码格式：`utf8mb4`
- 排序规则：`utf8mb4_0900_ai_ci`

## 三、实体关系说明
1. 学生用户一对多发布跑腿订单
2. 骑手完成认证后可接单，一对一绑定订单
3. 订单依次流转：发布→接单→配送→签收→评价
4. 学生、骑手均可发布论坛帖子与在线留言
5. 管理员统一管理公告、系统配置、骑手审核
6. 钱包表独立关联用户，记录资金变动
